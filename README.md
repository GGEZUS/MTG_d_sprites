# MTG Card Images

Image hosting for MTG Discord bot card images.

## Structure

- `cards/` - Card images organized by set code
- `boosters/` - Booster pack images
- `themedecks/` - Theme deck images
- `backs/` - Card back images (`mtg_back_1.jpg` is the default; future league backs go here too)

## GitHub Pages

Images are served via GitHub Pages at:
https://ggezus.github.io/MTG_d_sprites/

## Usage

Card images:
```
https://ggezus.github.io/MTG_d_sprites/cards/MIR/card_id.jpg
```

Booster images:
```
https://ggezus.github.io/MTG_d_sprites/boosters/mirage.png
```
